> 运维脚本也要能被别人接手：依赖固定、能测、有退出码、日志可读。这一篇是把它做成「工程」的最小集。
>
> 项目结构，虚拟环境，依赖锁定，pytest，类型检查，脚本骨架，分发

------

### 目录结构

```Shell
ops-scripts/
├── .venv/                 # 虚拟环境，不进版本库
├── requirements.txt       # 精确版本，见下
├── pyproject.toml         # 工具配置（ruff / mypy / pytest）
├── inspect_cluster.py     # 入口脚本
├── lib/                   # 可复用的模块
│   ├── __init__.py
│   └── k8s.py
└── tests/
    └── test_k8s.py
```

单文件脚本（< 200 行）就别建工程，直接一个 `.py` 加 shebang 即可；超过这个规模再上结构。

### 虚拟环境与依赖

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install requests pyyaml          # 开发期随手装
pip freeze > requirements.txt        # 导出精确版本
pip install -r requirements.txt      # 别人复现
```

```Shell
# requirements.txt 的写法对比
requests              # ❌ 漂移：下次装的可能是新版本
requests==2.32.3      # ✅ 锁定精确版本，运维脚本必须这样
```

**不要往系统 Python 里装东西**：很多发行版自带 Python 被系统工具依赖，污染后极难排查。

### 脚本骨架

一个能长期运行的脚本，这五件事缺一不可：

```python
#!/usr/bin/env python3
"""巡检集群异常 Pod，异常时退出码 1。"""
import argparse, logging, sys

log = logging.getLogger("inspect")

def parse_args() -> argparse.Namespace:
    p = argparse.ArgumentParser(description=__doc__)
    p.add_argument("-n", "--namespace", default="", help="限定命名空间")
    p.add_argument("--dry-run", action="store_true")
    p.add_argument("-v", "--verbose", action="store_true")
    return p.parse_args()

def main() -> int:
    args = parse_args()
    logging.basicConfig(
        level=logging.DEBUG if args.verbose else logging.INFO,
        format="%(asctime)s %(levelname)s %(message)s",
    )
    try:
        bad = find_unhealthy(args.namespace)
    except Exception:
        log.exception("执行失败")
        return 2                      # 2 = 执行错误，区别于 1 = 检查不通过
    if bad:
        for item in bad:
            log.warning("异常: %s", item)
        return 1
    log.info("全部正常")
    return 0

if __name__ == "__main__":
    sys.exit(main())
```

**退出码约定**（监控和 CI 都靠它判断）：

| 码 | 含义 |
| :-- | :-- |
| `0` | 正常 |
| `1` | 检查不通过（业务层面的异常） |
| `2` | 脚本自身执行失败（连不上、参数错） |

### pytest

```python
# tests/test_k8s.py
from lib.k8s import is_unhealthy

def test_pending_is_unhealthy():
    assert is_unhealthy({"status": {"phase": "Pending"}})

def test_running_is_healthy():
    assert not is_unhealthy({"status": {"phase": "Running"}})
```

```bash
pytest -q                     # 跑全部
pytest -q -k unhealthy        # 只跑名字匹配的
pytest --cov=lib              # 覆盖率
```

运维脚本不用追求覆盖率，**但纯函数（解析、判断、格式化）一定要有测试**——这类代码最容易改错，而且改错了不一定立刻暴露。

```python
# 用 monkeypatch 模拟外部依赖，避免测试真的去打 API
def test_probe_failure(monkeypatch):
    def boom(*a, **k):
        raise ConnectionError("refused")
    monkeypatch.setattr("lib.k8s.requests.get", boom)
    assert probe("10.0.0.1") is False
```

### 类型检查与风格

```python
def list_pods(namespace: str, *, limit: int = 100) -> list[dict]:
    ...
```

```bash
pip install ruff mypy
ruff check .          # 静态检查 + 风格（替代 flake8/isort/pyupgrade）
ruff format .         # 格式化（替代 black）
mypy lib/             # 类型检查
```

类型注解的核心价值不是「让 mypy 通过」，而是**IDE 能补全、重构时能发现调用点**。团队脚本尤其值得。

### 配置与环境变量

```python
import os

def env(name: str, default: str | None = None, *, required: bool = False) -> str:
    val = os.environ.get(name, default)
    if required and not val:
        raise SystemExit(f"缺少环境变量 {name}")
    return val

TOKEN = env("API_TOKEN", required=True)
TIMEOUT = int(env("API_TIMEOUT", "10"))
```

优先级：**命令行参数 > 环境变量 > 配置文件 > 代码默认值**。密钥永远走环境变量或密钥服务。

### 分发

| 方式 | 适用 | 命令 |
| :-- | :-- | :-- |
| 直接 `scp` 脚本 + 目标机装依赖 | 目标机可控 | `pip install -r requirements.txt` |
| `zipapp` 打包（纯标准库） | 无第三方依赖的脚本 | `python -m zipapp src -o tool.pyz` |
| `pex` / `shiv` | 带依赖的单文件可执行 | `pex . -o tool -c tool.py` |
| Docker 镜像 | 有复杂依赖、要长期运行 | 最稳，推荐 |
| `pyinstaller` | 交付给无 Python 的机器 | 体积大，运维场景少用 |

**运维场景首选「容器化分发」**：依赖、Python 版本、系统库全部固定，不会出现「我这儿能跑」。

### 在容器里跑定时脚本

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
ENTRYPOINT ["python", "inspect_cluster.py"]
```

配合 K8s CronJob 时注意：**退出码非 0 才会触发 Job 失败重试**；日志务必写 stdout。

### 核心概念

1. **依赖锁定精确版本**（`==`），运维脚本最怕「上次还能跑」。
2. **每个项目一个 venv**，不动系统 Python。
3. **退出码要分三种**：0 正常 / 1 检查不通过 / 2 执行失败。
4. **`main()` 返回 int + `sys.exit()`**，别在函数里到处 `exit()`。
5. **纯函数要写测试**（解析、判断、格式化），用 monkeypatch 隔离外部依赖。
6. **配置优先级固定**：命令行 > 环境变量 > 配置文件 > 默认值。
7. **分发优先用容器**，彻底消除环境差异。
