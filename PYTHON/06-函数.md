## 1. 最简单的函数

```python
def greet():
    """打印一句问候。"""        # 三引号紧跟在 def 下面 = 文档字符串
    print("hello")

greet()                          # 调用才会执行
```

```python
def check_port(host, port):
    """检查端口是否开放，返回 True/False。"""
    import socket
    with socket.socket() as s:
        s.settimeout(2)
        return s.connect_ex((host, port)) == 0
```

`def 函数名(参数):` → 缩进写函数体 → 用 `return` 返回结果（不写则返回 `None`）。

## 2. 参数的种类

```python
def deploy(name, replicas=1, *, namespace="default", dry_run=False):
    """
    必填参数：name
    默认参数：replicas
    仅限关键字参数：namespace、dry_run（星号之后）
    """
    print(f"{namespace}/{name} x{replicas} dry_run={dry_run}")

# 各种调用方式
deploy("web")                                    # 用默认值
deploy("web", 3)                                 # 位置传参
deploy("web", replicas=5)                        # 关键字传参（推荐，可读性好）
deploy("web", namespace="prod", dry_run=True)    # 星号后的必须写名字
deploy("web", 3, "prod")                         # ❌ 报错：星号后的不能按位置传
```

**默认参数的坑**（必背）：

```python
def bad(items=[]):          # ❌ 默认值只在定义时创建一次，所有调用共享
    items.append(1)
    return items

bad()    # [1]
bad()    # [1, 1]   ← 第二次带着上次的数据

def good(items=None):       # ✅ 用 None 占位
    if items is None:
        items = []
    items.append(1)
    return items
```

### 可变参数

```python
def run_all(*hosts, **options):
    """
    *hosts   → 收集所有位置参数，得到元组 ("a", "b")
    **options → 收集所有关键字参数，得到字典 {"user": "root"}
    """
    print(hosts)      # ('a', 'b')
    print(options)    # {'user': 'root'}

run_all("a", "b", user="root")

# 反过来：把列表/字典「拆开」传进去
hosts = ["a", "b"]
run_all(*hosts)

opts = {"user": "root"}
run_all("a", **opts)
```

## 3. 返回值

```python
def div(a, b):
    return a / b           # 有 return 就有返回值

def log_only(msg):
    print(msg)             # 没有 return → 返回 None

# 返回多个值：实际返回元组，调用处可自动解包
def parse_endpoint(url):
    host, _, port = url.rpartition(":")
    return host, int(port)

h, p = parse_endpoint("10.0.0.1:8080")

# 提前返回，减少嵌套（推荐写法）
def classify(status):
    if status == "Running":
        return "ok"
    if status == "Pending":
        return "wait"
    return "bad"           # 兜底放最后
```

## 4. 作用域

```python
count = 0                  # 全局变量

def f():
    print(count)           # ✅ 能读全局

def g():
    count = 1              # 这只是新建局部变量，不影响全局

def h():
    global count           # 声明要改全局（不推荐，容易出 bug）
    count = 1

def i():
    global count
    count += 1             # 要改全局必须 global
```

**原则**：函数尽量**只依赖参数、只通过返回值输出**，不要偷偷改全局变量。这样的函数最好测试、最好复用。

```python
# ❌ 依赖全局
def cleanup():
    for f in FILES: ...
    FILES.clear()

# ✅ 依赖参数
def cleanup(files):
    for f in files: ...
    return len(files)
```

## 5. lambda：一次性的小函数

```python
# 语法：lambda 参数: 表达式（只能写一个表达式，不能有多行）
square = lambda x: x * x
square(3)          # 9

# 真正用途：给 sort/max/min/filter 传「排序/比较的依据」
pods = [{"name": "web-1", "restarts": 3}, {"name": "web-2", "restarts": 12}]
sorted(pods, key=lambda p: p["restarts"])
max(pods, key=lambda p: p["restarts"])

# 不要给 lambda 起名字赋值，直接用 def 更清楚
```

    参数:
        name:      Pod 名称

类型注解**没有运行时约束**，但能带来：

- IDE 自动补全和参数提示
- `mypy` 静态检查能提前发现类型错误
- 别人（包括三个月后的你）一眼看懂输入输出

```python

def f(a: int, b: str = "", c: list[str] | None = None) -> dict[str, int]: ...
```

## 7. 生成器入门：省内存

```python
# 普通函数：一次性把所有结果算出来放进列表（占内存）
def all_logs(n):
    return [f"line-{i}" for i in range(n)]

# 生成器：用到时才产出一个（不占内存）
def iter_logs(n):
    for i in range(n):
        yield f"line-{i}"

for line in iter_logs(10_000_000):
    if "ERROR" in line:
        break          # 只算到这里的，后面的根本不生成
```

看到 `yield` 就是生成器。处理大文件、大日志时用它能避免 OOM。

## 8. 实战：把脚本重构成函数

```python
# 重构前：一坨流水账，无法复用、无法测试
# pods = get_pods(); for p in pods: ...（全写在主流程里）

# 重构后：每个函数只做一件事

def fetch_pods(namespace: str) -> list[dict]:
    """获取 Pod 列表。"""
    ...

def find_problems(pods: list[dict], restart_threshold: int = 10) -> list[dict]:
    """筛出有问题的 Pod（纯函数，好测试）。"""
    return [
        p for p in pods
        if p["status"] != "Running" or p["restarts"] > restart_threshold
    ]

def report(problems: list[dict]) -> None:
    """打印报告。"""
    if not problems:
        print("全部正常")
        return
    for p in problems:
        print(f"[异常] {p['name']}: {p['status']}, 重启 {p['restarts']} 次")

def main() -> int:
    """主流程只负责串联，不写具体逻辑。"""
    pods = fetch_pods("prod")
    problems = find_problems(pods)
    report(problems)
    return 1 if problems else 0        # 退出码交给调用方

if __name__ == "__main__":
    raise SystemExit(main())
```

这种「一个函数一件事 + main 只做串联」的结构，是所有运维脚本的推荐骨架。

## 核心概念

1. **一个函数只做一件事**，名字要能说明它做什么。
2. **默认参数不要用可变对象**（`[]`、`{}`），用 `None` 占位。
3. **星号 `*` 之后的参数只能按关键字传**，适合放一堆可选开关。
4. **`*args` 收位置参数成元组，`**kwargs` 收关键字参数成字典**。
5. **优先「参数进、返回值出」**，少用 `global`。
6. **提前 `return` 减少嵌套**，比层层 if 清晰。
7. **类型注解 + 文档字符串**，是给未来的自己留的说明书。
8. **`yield` 生成器省内存**，处理大日志时优先考虑。
