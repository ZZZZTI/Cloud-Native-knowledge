



### 字符串

```Shell
line = "  2026-10-27 ERROR disk full  \n"

# 1. strip()：去掉首尾空白（含换行 \n）—— 读文件时必用！
print(line.strip())        # "2026-10-27 ERROR disk full"

# 2. split()：按分隔符切成列表
line2 = "2026-10-27|ERROR|disk full"
parts = line2.split("|")
print(parts)               # ['2026-10-27', 'ERROR', 'disk full']
print(parts[1])            # ERROR

# 不带参数的 split()：按"任意空白"切，自动去多余空格
line3 = "nginx   80   running"
print(line3.split())       # ['nginx', '80', 'running']

# 3. startswith / endswith：判断开头结尾（过滤日志超常用）
print(line2.startswith("2026"))    # True
print(line2.endswith("full"))      # True

# 4. replace：替换
print("ERROR disk full".replace("ERROR", "WARN"))   # "WARN disk full"

# 5. join：把列表拼成字符串
ports = ["80", "443", "3306"]
print(",".join(ports))     # "80,443,3306"

# 6. 大小写
print("Error".lower())     # "error"
print("error".upper())     # "ERROR"

# 7. in：判断子串在不在（比 startswith 更宽松）
print("ERROR" in line2)    # True

# 8. 切片：取字符串的一段
s = "2026-10-27"
print(s[0:4])              # "2026"（取索引 0 到 3，不含 4）
print(s[:4])               # "2026"（开头省略也行）
print(s[-5:])              # "10-27"（最后 5 个字符）


line = "nginx|80|running"
name, port, status = line.split("|")     # 左边三个变量接右边三个值
print(name)      # nginx
print(port)      # 80（还是字符串！要数字得 int(port)）
print(status)    # running
```

### 文件读取

```Shell
with open("access.log", "r", encoding="utf-8") as f:
    for line in f:                 # 逐行读，一行一行处理
        line = line.strip()        # 去掉行尾的 \n 和空格
        print(line)
        
        
with open("report.txt", "w", encoding="utf-8") as f:
    f.write("第一行\n")            # 注意：write 不会自动加换行，要自己写 \n
    f.write("第二行\n")

# "w" = 覆盖写（文件存在会清空！）
# "a" = 追加写（文件存在会在末尾追加）
```
