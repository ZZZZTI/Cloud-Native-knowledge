## 1. 定义与三种引号

```python
s1 = 'abc'          # 单引号
s2 = "abc"          # 双引号，和单引号完全等价
s3 = """多行
字符串"""            # 三引号可以跨行

# 引号里套引号：外层用双引号，内层就可以用单引号
msg = "He said 'hello'"

# 转义字符
"第一行\n第二行"      # \n 换行
"制表\t分隔"          # \t 制表符
"路径 C:\\temp"       # \\ 表示一个反斜杠
"引号：\""            # \" 表示引号本身

# 原始字符串：不处理转义，写正则/路径时很有用
r"\d+\.\d+"          # 反斜杠就是反斜杠
```

## 2. 索引与切片

```python
s = "kubernetes"
#    0123456789

s[0]        # 'k'      第一个字符
s[-1]       # 's'      最后一个字符
s[0:4]      # 'kube'   左闭右开，取下标 0,1,2,3
s[:4]       # 'kube'   省略起点 = 从头开始
s[4:]       # 'rnetes' 省略终点 = 到末尾
s[::2]      # 'kbre'   每隔一个取一个
s[::-1]     # 'setenrekub'  反转字符串

len(s)      # 10       长度
```

**切片不会越界报错**，这点和索引不同：

```python
s[100]        # ❌ IndexError
s[100:200]    # ✅ ''  返回空字符串
```

## 3. 最高频的方法（背下来）

```python
line = "  2026-10-27 10:00:01 ERROR 连接超时  \n"

line.strip()                    # 去掉首尾空白（含 \n）← 读文件必用
line.lstrip()                   # 只去左边
line.rstrip()                   # 只去右边
line.strip("\n")                # 只去换行，保留其他

"a,b,c".split(",")              # ['a', 'b', 'c']        按分隔符切
"a  b   c".split()              # ['a','b','c']          不传参 = 按任意空白切
"a,b,c".split(",", 1)           # ['a', 'b,c']           最多切 1 次

"-".join(["web", "1"])          # 'web-1'                列表拼成字符串

"hello.log".startswith("hello") # True    判断开头
"app.log".endswith(".log")      # True    判断结尾
"error" in line                 # True    子串判断

"ERROR".lower()                 # 'error'
"error".upper()                 # 'ERROR'
"  x  ".strip().lower()         # 链式调用，从左到右依次执行

"a-b-c".replace("-", "_")       # 'a_b_c'
"abc".replace("b", "")          # 'ac'    删除字符

"8080".isdigit()                # True    全是数字
"abc".isalpha()                 # True
"  ".isspace()                  # True
line.count("ERROR")             # 出现次数
line.find("ERROR")              # 首次出现的下标，找不到返回 -1
```

**为什么 `strip()` 这么重要**：从文件按行读出来的每行末尾都带 `\n`，不 strip 直接比较会永远不相等。

```python
if line == "ERROR":        # ❌ 实际是 "ERROR\n"，永远不成立
if line.strip() == "ERROR":  # ✅
```

## 4. 格式化：f-string

```python
name, ip, port = "web-1", "10.0.0.1", 8080

f"{name} 在 {ip}:{port}"          # 直接插值
f"{port:05d}"                     # 0008080... 补零到 5 位
f"{3.14159:.2f}"                  # 3.14
f"{0.856:.1%}"                    # 85.6%
f"{name:^10}|"                    # 居中
f"{'a':<5}|{'b':>5}|"             # 左对齐 / 右对齐

# 表达式、函数调用都能写在花括号里
f"{len(name)} 个字符"
f"{name.upper()}"

# 多行 f-string（3.12+ 可以直接在花括号里换行）
cmd = f"kubectl -n {ns} get pods"
```

## 5. 编码：不写就是坑

```python
# 写文件/读文件都显式指定 UTF-8
open("a.txt", "w", encoding="utf-8").write("中文")
open("a.txt", encoding="utf-8").read()

# 数据脏（混入非法字节）时，别让脚本崩
open("app.log", encoding="utf-8", errors="replace").read()

# 字符串 ↔ 字节
"中文".encode("utf-8")        # b'\xe4\xb8\xad\xe6\x96\x87'
b"\xe4\xb8\xad".decode("utf-8")  # '中'

# 长度：字符数 vs 字节数
len("中文")                   # 2   ← 字符数
len("中文".encode("utf-8"))   # 6   ← 字节数
```

运维场景里最常见的乱码原因是**没指定编码，用了系统默认值**。永远显式写 `encoding="utf-8"`。

## 6. 正则：从文本里抠出字段

```python
import re

text = '10.0.0.1 - - [27/Oct/2026:10:00:01 +0800] "GET /api/x HTTP/1.1" 502 1234'

# 编译一次，循环里复用（性能差好几倍）
pattern = re.compile(r'(?P<ip>\d+\.\d+\.\d+\.\d+).*?"(?P<method>\w+) (?P<path>\S+).*?" (?P<status>\d{3})')

m = pattern.search(text)
if m:
    print(m.group("ip"))       # 10.0.0.1
    print(m.group("status"))   # 502
    print(m.groupdict())       # {'ip': ..., 'method': ..., 'path': ..., 'status': ...}
```

常用函数：

```python
re.match(r"^ERROR", line)        # 从开头匹配
re.search(r"timeout=\d+", line)  # 全文找第一个
re.findall(r"\d+", "a1b22")      # ['1', '22']  找出所有
re.sub(r"\s+", " ", line)        # 把连续空白压成一个空格
re.split(r"[,\s]+", "a, b  c")   # ['a','b','c']
```

常用元字符速查：

| 符号 | 含义 | 例子 |
| :-- | :-- | :-- |
| `.` | 任意字符（除换行） | `a.c` 匹配 `abc` |
| `\d` `\w` `\s` | 数字 / 字母数字下划线 / 空白 | `\d+` 匹配 `123` |
| `*` `+` `?` | 0+ / 1+ / 0或1 次 | `\d+` |
| `{n,m}` | n 到 m 次 | `\d{3}` |
| `^` `$` | 行首 / 行尾 | `^ERROR` |
| `[abc]` `[^abc]` | 集合 / 排除 | `[0-9]` |
| `(?P<name>...)` | 命名分组 | 见上例 |

⚠️ **正则只做字段级提取**。要解析完整结构（JSON/YAML），用专门的库，别硬写正则。

## 7. 实战：统计日志里的状态码

```python
import re
from collections import Counter
from pathlib import Path

# 预编译，循环里不重复编译
LINE = re.compile(r'"(?P<method>\S+) (?P<path>\S+).*?" (?P<status>\d{3})')

counter = Counter()
errors = Counter()

# 逐行读，不要 read() 全读进内存
with Path("/var/log/nginx/access.log").open(encoding="utf-8", errors="replace") as f:
    for line in f:
        m = LINE.search(line)
        if not m:
            continue                      # 不匹配的行直接跳过，不要让脚本崩
        d = m.groupdict()
        counter[d["status"]] += 1
        if d["status"].startswith("5"):
            errors[d["path"]] += 1

print("状态码分布：", counter.most_common())
print("5xx 最多的路径：", errors.most_common(5))
```

## 核心概念

1. **`strip()` 是读文件后的必备动作**，否则行尾 `\n` 会让比较永远失败。
2. **`split()` 不传参按任意空白切**，能自动处理多个空格。
3. **`join()` 比循环 `+=` 快得多**，拼接列表用 `"-".join(list)`。
4. **f-string 是格式化首选**，支持精度、对齐、百分比。
5. **打开文件永远显式 `encoding="utf-8"`**，脏数据加 `errors="replace"`。
6. **正则先 `re.compile`**，循环里复用；只做字段提取，别解析结构。
7. **`rpartition`/`rsplit` 从右往左**，处理 `host:port` 这类结构很方便。
