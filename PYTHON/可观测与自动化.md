### 结构化日志

日志平台（Loki / ES）要的是可检索的字段，不是一行拼接文本。

```python
import logging, json, sys

class JsonFormatter(logging.Formatter):
    def format(self, record: logging.LogRecord) -> str:
        payload = {
            "ts": self.formatTime(record, "%Y-%m-%dT%H:%M:%S%z"),
            "level": record.levelname,
            "logger": record.name,
            "msg": record.getMessage(),
        }
        if record.exc_info:
            payload["exc"] = self.formatException(record.exc_info)
        # 通过 extra= 传入的字段一并输出
        for k, v in record.__dict__.items():
            if k not in logging.LogRecord.__dict__ and not k.startswith("_"):
                payload.setdefault(k, v)
        return json.dumps(payload, ensure_ascii=False)

handler = logging.StreamHandler(sys.stdout)
handler.setFormatter(JsonFormatter())
logging.basicConfig(level=logging.INFO, handlers=[handler])

log = logging.getLogger("agent")
log.info("巡检完成", extra={"hosts": 42, "failed": 3})
```

**容器里的日志必须写到 stdout**，交给采集器统一收集，不要自己写文件。

### Prometheus exporter

`prometheus_client` 是标准做法：定义指标 + 起一个 HTTP 端口暴露 `/metrics`。

```python
from prometheus_client import start_http_server, Counter, Gauge, Histogram
import time, random

# 指标类型的选择
REQUESTS = Counter("probe_requests_total", "探测总次数", ["target", "result"])
LATENCY  = Histogram("probe_latency_seconds", "探测耗时", ["target"],
                     buckets=(.05, .1, .25, .5, 1, 2.5, 5, 10))
UP       = Gauge("probe_up", "目标是否可达", ["target"])

def probe(target: str) -> None:
    start = time.time()
    ok = random.random() > 0.1                    # 换成真实的探测逻辑
    REQUESTS.labels(target=target, result="ok" if ok else "fail").inc()
    LATENCY.labels(target=target).observe(time.time() - start)
    UP.labels(target=target).set(1 if ok else 0)

if __name__ == "__main__":
    start_http_server(9101)                       # /metrics 端口
    while True:
        for t in ("api", "web", "db"):
            probe(t)
        time.sleep(15)
```

| 类型 | 含义 | 典型用法 |
| :-- | :-- | :-- |
| `Counter` | 只增不减 | 请求数、错误数 |
| `Gauge` | 可增可减 | 当前连接数、是否可用、队列长度 |
| `Histogram` | 分桶统计 | 延迟分布，配合 `histogram_quantile` 算 P99 |
| `Summary` | 分位数 | 客户端分位，聚合时不能跨实例 |

**Counter 命名约定**：以 `_total` 结尾；单位写进名字（`_seconds`、`_bytes`）。

### OpenTelemetry

统一 Metrics / Logs / Traces 的标准，适合给应用做埋点而不是写 exporter。

```python
from opentelemetry import trace
from opentelemetry.sdk.trace import TracerProvider
from opentelemetry.sdk.trace.export import BatchSpanProcessor
from opentelemetry.exporter.otlp.proto.grpc.trace_exporter import OTLPSpanExporter

provider = TracerProvider()
provider.add_span_processor(
    BatchSpanProcessor(OTLPSpanExporter(endpoint="http://otel-collector:4317", insecure=True))
)
trace.set_tracer_provider(provider)
tracer = trace.get_tracer(__name__)

with tracer.start_as_current_span("probe_cluster") as span:
    span.set_attribute("cluster", "prod")
    try:
        do_work()
    except Exception as e:
        span.record_exception(e)
        span.set_status(trace.Status(trace.StatusCode.ERROR))
        raise
```

### Kubernetes client

```python
from kubernetes import client, config

# 集群内跑（Pod 里）用 incluster，本地调试用 kubeconfig
try:
    config.load_incluster_config()
except config.ConfigException:
    config.load_kube_config()

v1 = client.CoreV1Api()

# 列出所有异常 Pod
for pod in v1.list_pod_for_all_namespaces(field_selector="status.phase!=Running").items:
    print(pod.metadata.namespace, pod.metadata.name, pod.status.phase)

# 读日志
print(v1.read_namespaced_pod_log("web-1", "prod", tail_lines=100))

# 在容器里执行命令
resp = v1.connect_get_namespaced_pod_exec(
    "web-1", "prod", container="app",
    command=["sh", "-c", "df -h /"], stderr=True, stdout=True, stdin=False, tty=False,
)
print(resp)
```

```python
# 删 Pod（重启）：注意它会被控制器重建
v1.delete_namespaced_pod("web-1", "prod", grace_period_seconds=0)
```

**RBAC 要先给足权限**：脚本用的 ServiceAccount 需要 `pods/get`、`pods/log`、`pods/exec` 等，别图省事绑 `cluster-admin`。

### 远程批量执行

```python
import paramiko

def run(host: str, cmd: str, user: str = "root", timeout: int = 10) -> tuple[int, str]:
    c = paramiko.SSHClient()
    c.set_missing_host_key_policy(paramiko.AutoAddPolicy())   # 生产建议用已知 hosts
    c.connect(host, username=user, timeout=timeout,
              key_filename="/home/ops/.ssh/id_ed25519")
    try:
        _, out, err = c.exec_command(cmd, timeout=timeout)
        return out.channel.recv_exit_status(), out.read().decode() + err.read().decode()
    finally:
        c.close()
```

并发版把它丢进 `ThreadPoolExecutor` 即可（见 `并发.md`）。

### 核心概念

1. **日志写 stdout 且结构化（JSON）**，字段可检索才有价值。
2. **exporter 用 `prometheus_client`**，Counter 名字带 `_total`、单位写进名字。
3. **Histogram 才能算 P99**，且能跨实例聚合；Summary 不能。
4. **K8s client 在集群内用 `load_incluster_config`**，本地调试回退到 kubeconfig。
5. **脚本的 ServiceAccount 只给必需权限**，不要 `cluster-admin`。
6. **远程执行用 `paramiko` + 线程池**，每个连接都要 `close()`。
7. **云 SDK 的分页与限流必须处理**，否则大账号下必然漏数据或被 throttling。
