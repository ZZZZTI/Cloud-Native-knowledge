## 1. 变量：给值起个名字

```python
# Python 不需要提前声明类型，赋值即创建
host = "10.0.0.1"      # 字符串
port = 6443            # 整数
ratio = 0.75           # 浮点数
ready = True           # 布尔值

# 同一行给多个变量赋值
x, y = 1, 2

# 交换两个变量（不用中间变量）
x, y = y, x

# 变量名规则：字母/数字/下划线，不能数字开头，区分大小写
# 推荐小写 + 下划线（snake_case）：pod_count、node_name、is_healthy
```

**没有「声明」这一步，但有「赋值前不能使用」**：

```python
print(abc)      # ❌ NameError: name 'abc' is not defined
abc = 1
print(abc)      # ✅ 1
```

## 2. 数字

```python
10          # 整数 int
3.14        # 浮点数 float
1_000_000   # 下划线只是方便阅读，等于 1000000

# 四则运算
7 + 3       # 10
7 - 3       # 4
7 * 3       # 21
7 / 3       # 2.3333...   ← 注意：/ 永远得到浮点数
7 // 3      # 2           ← 整除，向下取整
7 % 3       # 1           ← 取余（判断奇偶、分片常用）
7 ** 3      # 343         ← 幂

# 运算优先级：** > * / // % > + -
(1 + 2) * 3     # 用括号明确优先级，别靠记忆

# 浮点数精度陷阱
0.1 + 0.2 == 0.3          # False！
abs(0.1 + 0.2 - 0.3) < 1e-9   # ✅ 比较浮点用误差范围
```

------

## 3. 布尔值与 None

```python
True / False        # 只有首字母大写，true/false 是错的

# 各种「假值」（在 if 判断里等价于 False）
bool(0)         # False
bool("")        # False   空字符串
bool([])        # False   空列表
bool({})        # False   空字典
bool(set())     # False   空集合
bool(None)      # False

# 其余都是真值
bool("0")       # True   ← 注意："0" 是非空字符串，为真
bool([0])       # True   ← 非空列表

# None：表示「什么都没有」，不是 0、不是 ""、不是 False
result = None
if result is None:        # ✅ 判断 None 永远用 is
    print("还没有结果")

if result == None:        # ❌ 不要这样写
    pass
```

## 4. 类型转换

```python
int("123")        # 123        字符串 → 整数
int("abc")        # ❌ ValueError，转换失败会抛异常
float("3.14")     # 3.14
str(123)          # "123"      任何东西 → 字符串
bool(1)           # True

# 输入的数字一定要转换！input() 拿到的永远是字符串
age = input("年龄：")      # 用户输入 25，age 是 "25" 不是 25
age = int(input("年龄：")) # ✅ 转换成整数

# 安全转换：不确定内容是否合法时，用 try 兜底
def to_int(s, default=0):
    try:
        return int(s)
    except (ValueError, TypeError):
        return default

to_int("8080")   # 8080
to_int("abc")    # 0
```

## 5. 运算符

```python
# 比较运算，结果是布尔值
1 == 1      # True   等于（两个等号！）
1 != 2      # True   不等于
3 > 2       # True
3 >= 3      # True
"a" < "b"   # True   字符串按字典序比较

# 逻辑运算
True and False   # False   两个都真才真
True or False    # True    一个真就真
not True         # False   取反

# 短路求值：and/or 左边能确定结果时，右边不会执行
# 利用这个特性写默认值
name = user_input or "unknown"    # 空字符串 → "unknown"

# 成员运算
"8080" in "http://x:8080"     # True
"web" in ["web-1", "web-2"]   # False（要完全相等，不是子串）

# 身份运算
a = [1, 2]
b = [1, 2]
a == b      # True    值相等
a is b      # False   不是同一个对象
```

`==` 比的是**值**，`is` 比的是**是不是同一个对象**。只有判断 `None`/`True`/`False` 时才用 `is`。

## 6. 输出：print

```python
print("hello")
print("a", "b", "c")              # a b c（默认用空格分隔）
print("a", "b", sep="-")          # a-b（自定义分隔符）
print("end 不换行", end="")        # 默认结尾换行，改成空字符串就不换行
print()

# f-string：最推荐的格式化方式（Python 3.6+）
name, port = "api", 8080
print(f"服务 {name} 监听 {port}")
print(f"耗时 {1.23456:.2f} 秒")        # 保留两位小数
print(f"编号 {7:03d}")                 # 补零成 007
print(f"{'左对齐':<10}|")              # 左对齐占 10 位
print(f"{'右对齐':>10}|")              # 右对齐占 10 位
print(f"{0.856:.1%}")                  # 百分比 85.6%

# 不推荐：+ 拼接（类型不匹配就报错，且慢）
print("服务 " + name + " 监听 " + str(port))   # 必须手动 str()

# 调试用：直接把变量名和值都打出来
x = 42
print(f"{x=}")       # x=42   ← 这是最快的调试打印
```

## 7. 输入：input

```python
# input() 永远返回字符串，并且会阻塞等待回车
name = input("请输入节点名：")

# 需要数字就转换，并且要防用户乱输
raw = input("请输入端口：")
try:
    port = int(raw)
except ValueError:
    print("端口必须是数字")
    port = 8080
```

**运维脚本里尽量少用 `input()`**：脚本通常无人值守，交互式输入会挂住。用命令行参数（见 `12-标准库运维常用.md` 的 argparse）代替。

## 8. 查看类型

```python
type(123)            # <class 'int'>
type("abc")          # <class 'str'>
isinstance(123, int)          # True
isinstance("123", (int, str)) # True   可以传元组，任一匹配即可
isinstance(True, int)         # True   ← 坑：布尔是整数的子类
```

判断类型优先用 `isinstance()`，它支持继承关系；`type(x) == int` 太死板。

## 核心概念

1. **变量赋值即创建**，但赋值前使用会 `NameError`。
2. **`/` 得到浮点数，`//` 是整除，`%` 是取余**。
3. **空值判断看真假**：`0`、`""`、`[]`、`{}`、`None` 都是假值，但 `"0"` 是**真**。
4. **`input()` 永远返回字符串**，要数字必须转换。
5. **f-string 是格式化首选**，比 `+` 拼接清晰且不会类型报错。
6. **比较值用 `==`，判断 `None` 用 `is`**。
7. **浮点数不要用 `==` 比较**，用误差范围。
