## 1. json / configparser / tomllib ★★★ —— JSON / INI / TOML 读写

### json

```
json.load(f) / json.loads(s)            解析，得到 dict/list
json.dump(o, f) / json.dumps(o)         序列化
json.dumps(o, ensure_ascii=False)       中文不转义（必加）
json.dumps(o, indent=2)                 美化，给人看
json.dumps(o, sort_keys=True)           key 排序，便于 diff
json.dumps(o, default=str)              无法序列化的对象转成 str（datetime/Decimal）
json.dumps(o, allow_nan=False)          NaN/Infinity 直接报错（严格 JSON）
json.JSONDecodeError                    解析失败
```

```Python
import json
from datetime import datetime

data = {"name": "web", "replicas": 3, "注释": "中文"}

# ==== 写：三个参数最常用 ====
text = json.dumps(data, ensure_ascii=False, indent=2, sort_keys=True)
print(text)

# ==== 读：一定要兜底 ====
try:
    cfg = json.loads(open("conf.json", encoding="utf-8").read())
except json.JSONDecodeError as e:
    print(f"配置不是合法 JSON: 行{e.lineno} 列{e.colno} {e.msg}")
    cfg = {}

# ==== 序列化 datetime ====
json.dumps({"ts": datetime.now()}, default=str)
```

⚠️ 坑：

- 不加 `ensure_ascii=False`，中文会变成 `\u4e2d\u6587`
- JSON **不支持注释**、**不允许尾随逗号**；`json5` 才能容忍
- `json.loads("NaN")` 居然能过（非标准），要严格就 `allow_nan=False`
- 大文件别 `json.load`，用 `ijson` 或按行读 JSON Lines

### configparser：INI 格式

```
ConfigParser()
parser.read(path, encoding="utf-8")     读（文件不存在不报错，要看返回值）
parser.read_string(text)                从字符串读
parser.sections()                       ['db', 'log']
parser.options("db")                    ['host', 'port']
parser.items("db")                      [('host','x'), ('port','5432')]
parser.get("db", "host")                取字符串
parser.getint / getfloat / getboolean   类型转换
parser.has_section / has_option         是否存在
parser.set("db", "port", "5433")        改
parser.add_section("new")               加段
parser.write(f)                         写回
parser["db"]["host"]                    字典式访问
parser["DEFAULT"]                       默认值段，所有段都能读到
```

```Python
import configparser

parser = configparser.ConfigParser()
# ⚠️ 返回值是「成功读取的文件列表」，失败时是空列表而不是异常
if not parser.read("/etc/app/config.ini", encoding="utf-8"):
    raise FileNotFoundError("配置文件不存在")

host = parser["db"]["host"]                       # 字典式
port = parser.getint("db", "port")                # 带类型转换
debug = parser.getboolean("app", "debug")
level = parser.get("app", "level", fallback="INFO")   # 给默认值

# ==== 默认值：DEFAULT 段对所有 section 生效 ====
# [DEFAULT]
# timeout = 30
# [db]
# host = 1.2.3.4
# 此时 parser["db"]["timeout"] == "30"
```

⚠️ **插值陷阱**：`get()` 默认开启插值，值里的 `%` 会被当成占位符（如密码含 `%` 就报 `InterpolationSyntaxError`）。

```Python
parser = configparser.ConfigParser(interpolation=None)   # ✅ 关掉插值
```

### tomllib：TOML（3.11+）

```
tomllib.load(f)         ⚠️ 必须以二进制模式打开 "rb"
tomllib.loads(s)        从字符串读
```

```Python
import tomllib

# ⚠️ 必须 "rb"，传文本模式会报错
with open("pyproject.toml", "rb") as f:
    cfg = tomllib.load(f)

print(cfg["tool"]["ruff"]["line-length"])
```

⚠️ `tomllib` **只能读不能写**。要写 TOML 用 `tomli-w` 或手动拼。

## 2. PyYAML ★★★ —— YAML 解析（标准库没有）

标准库没有 YAML，K8s 清单/Ansible/CI 配置全靠它。

```
yaml.safe_load(f)               单文档 → dict
yaml.safe_load_all(f)           多文档（--- 分隔）→ 生成器
yaml.safe_dump(doc, f)          写回
yaml.safe_dump_all(docs, f)     多文档写回
yaml.safe_dump(doc, allow_unicode=True)   中文正常输出（必加）
yaml.safe_dump(doc, sort_keys=False)      保持原顺序（必加）
yaml.safe_dump(doc, default_flow_style=False)   块状风格（人可读）
yaml.YAMLError                  解析失败
```

```Python
import yaml

# ==== 读单文档 ====
with open("deploy.yaml", encoding="utf-8") as f:
    doc = yaml.safe_load(f)

# ==== 读多文档（kubectl apply -f 那种）====
with open("all.yaml", encoding="utf-8") as f:
    docs = list(yaml.safe_load_all(f))

for d in docs:
    print(d["kind"], d["metadata"]["name"])

# ==== 写回：两个参数必加 ====
yaml.safe_dump(doc, allow_unicode=True, sort_keys=False)
```

⚠️ **安全陷阱**：只用 `safe_load`。

```Python
yaml.safe_load(s)        # ✅ 只构造基本类型
yaml.load(s)             # ❌ 默认 Loader 能构造任意 Python 对象
yaml.load(s, Loader=yaml.FullLoader)   # 比 safe 宽松，仍不建议
```

⚠️ **类型自动转换**（YAML 1.1 的坑）：

```yaml
enabled: yes        # → True（不是 "yes"）
country: no         # → False（挪威问题！）
version: 1.10       # → 1.1（float，不是 "1.10"）
zip: 00123          # → 123（前导零丢失）
name: null          # → None
time: 12:30         # → 750（sexagesimal，YAML 1.1 特性）
```

**版本号、编号、布尔开关一律加引号**。

```Python
# ==== 保留字面量 ====
yaml.safe_load('version: "1.10"')      # {'version': '1.10'}  ✅
yaml.safe_load('version: 1.10')        # {'version': 1.1}     ❌
```

## 3. csv / sqlite3 ★★ —— 报表数据、轻量任务记录

### csv

```
csv.reader(f)                          按行返回 list
csv.DictReader(f)                      按行返回 dict（推荐）
reader.fieldnames                       列名列表
reader.line_num                         当前行号
csv.writer(f) / csv.DictWriter(f, fieldnames=)
writer.writeheader()                    写表头
writer.writerows(rows)                  批量写
csv.QUOTE_MINIMAL / QUOTE_ALL / QUOTE_NONNUMERIC
```

```Python
import csv

# ==== 读：DictReader 按列名取值，比下标稳 ====
with open("metrics.csv", encoding="utf-8", newline="") as f:
    for row in csv.DictReader(f):
        print(row["host"], row["cpu"])

# ==== 写 ====
rows = [{"host": "k8s-01", "cpu": 8}, {"host": "k8s-02", "cpu": 16}]
with open("out.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["host", "cpu"])
    writer.writeheader()
    writer.writerows(rows)
```

⚠️ `newline=""` 不加会在 Windows 上多出空行；编码必须显式 utf-8（Excel 要 `utf-8-sig` 才不乱码）。

### sqlite3

```
sqlite3.connect(path)                  连库（文件不存在自动创建）
conn.cursor()                          游标
cur.execute(sql, params)               执行一条（params 用 ? 占位）
cur.executemany(sql, seq)              批量执行
cur.fetchone() / fetchmany(n) / fetchall()
conn.commit() / rollback() / close()
conn.row_factory = sqlite3.Row         让结果能按列名访问
conn.execute(...)                      连接对象也能直接 execute
with conn:                             上下文管理器 = 自动 commit/rollback（不是关连接）
```

```Python
import sqlite3

conn = sqlite3.connect("/var/lib/ops/tasks.db")
conn.row_factory = sqlite3.Row        # 之后 row["name"] 可用
cur = conn.cursor()

# ==== 建表（幂等）====
cur.execute("""
CREATE TABLE IF NOT EXISTS task (
    id      INTEGER PRIMARY KEY AUTOINCREMENT,
    name    TEXT NOT NULL,
    status  TEXT NOT NULL,
    ts      TEXT NOT NULL
)
""")

# ==== 插入：永远用 ? 占位，不要拼字符串 ====
cur.executemany(
    "INSERT INTO task(name, status, ts) VALUES (?, ?, ?)",
    [("backup", "ok", "2026-10-27T10:00:00"),
     ("cleanup", "fail", "2026-10-27T10:05:00")],
)
conn.commit()

# ==== 查询 ====
cur.execute("SELECT name, status FROM task WHERE status = ?", ("fail",))
for row in cur.fetchall():
    print(row["name"], row["status"])

# ==== 事务：要么全成要么全滚 ====
try:
    with conn:                        # 异常自动 rollback，正常自动 commit
        conn.execute("UPDATE task SET status='ok' WHERE name='cleanup'")
except sqlite3.Error as e:
    print("事务失败:", e)

conn.close()
```

⚠️ 坑：

- **SQL 拼接字符串 = SQL 注入**，一律用 `?` 占位
- `with conn:` 管的是**事务**，不会关闭连接，仍要 `conn.close()`
- sqlite 同一时刻只允许一个写者，多进程写会 `database is locked`（加 `timeout=10`）
- `fetchall()` 大结果集会全读进内存，改用 `fetchmany`

## 4. Jinja2 ★★ —— 模板渲染，生成 nginx.conf 等

生成配置文件的标配：模板 + 变量 → 输出。

### 基本用法

```
from jinja2 import Environment, FileSystemLoader, Template, StrictUndefined

env = Environment(
    loader=FileSystemLoader("templates"),   # 模板目录
    autoescape=False,                       # 生成配置文件不要 HTML 转义
    trim_blocks=True,                       # {% %} 后的换行去掉
    lstrip_blocks=True,                     # {% %} 前的缩进去掉
    undefined=StrictUndefined,              # 变量缺失直接报错（推荐）
)
tpl = env.get_template("nginx.conf.j2")
out = tpl.render(server_name="api.example.com", upstreams=["10.0.0.1", "10.0.0.2"])

Template("hello {{ name }}").render(name="x")    # 从字符串渲染
```

### 模板语法

```
{{ var }}                输出变量
{{ var|default("x") }}   变量缺失时用默认值
{{ items|join(", ") }}   过滤器
{{ value|int }} / |float / |upper / |lower / |trim
{{ dict.key }}           访问字典
{{ list[0] }}            访问列表

{% if cond %} ... {% elif %} ... {% else %} ... {% endif %}
{% for x in xs %} ... {% endfor %}
{% for k, v in d.items() %} ... {% endfor %}
{% for x in xs %}
  {{ loop.index }}       从 1 开始
  {{ loop.index0 }}      从 0 开始
  {{ loop.first }} / loop.last
{% endfor %}

{# 注释 #}
{% raw %} {{ 原样输出 }} {% endraw %}
```

### 模板示例

```Jinja
{# templates/nginx.conf.j2 —— 注意用 {# #} 注释，不是 Python 的 # #}
upstream backend {
{% for ip in upstreams %}
    server {{ ip }}:{{ port|default(8080) }} weight=1;
{% endfor %}
}

server {
    listen 80;
    server_name {{ server_name }};

{% if enable_tls %}
    listen 443 ssl;
    ssl_certificate     {{ cert_path }};
    ssl_certificate_key {{ key_path }};
{% endif %}

    location / {
        proxy_pass http://backend;
        proxy_set_header Host $host;
    }
}
```

### Python 侧渲染

```Python
from pathlib import Path
from jinja2 import Environment, FileSystemLoader, StrictUndefined

env = Environment(
    loader=FileSystemLoader("templates"),
    autoescape=False,
    trim_blocks=True,
    lstrip_blocks=True,
    undefined=StrictUndefined,       # 变量没传就报错，避免生成残缺配置
)
tpl = env.get_template("nginx.conf.j2")
conf = tpl.render(
    server_name="api.example.com",
    upstreams=["10.0.0.1", "10.0.0.2"],
    port=8080,
    enable_tls=True,
    cert_path="/etc/ssl/api.crt",
    key_path="/etc/ssl/api.key",
)

# 生成后先落地到临时文件，再原子替换 + reload
Path("/tmp/nginx.conf.new").write_text(conf, encoding="utf-8")
```

⚠️ 坑：

- 生成 nginx 配置时 `autoescape` 必须是 `False`，否则 `&` 会变成 `&amp;`
- `undefined` 默认是静默空串，会生成「缺一行」的配置——**一定要用 `StrictUndefined`**
- 模板里的 `$host`、`$remote_addr` 是 nginx 变量，Jinja2 不会动它，但要小心 `{%` 冲突
- `trim_blocks` + `lstrip_blocks` 一起开，生成的配置才不会有大量空行

## 5. pydantic-settings / Dynaconf ★★/★ —— 类型安全、多环境配置管理

### pydantic-settings：类型安全的配置

```
from pydantic_settings import BaseSettings, SettingsConfigDict
from pydantic import Field

class Settings(BaseSettings):
    model_config = SettingsConfigDict(
        env_file=".env",            从 .env 读
        env_prefix="APP_",          环境变量前缀
        case_sensitive=False,
    )
    host: str = "0.0.0.0"
    port: int = 8080
    debug: bool = False
    token: str = Field(..., min_length=8)     必填 + 校验
```

```Python
from pydantic import Field, ValidationError
from pydantic_settings import BaseSettings, SettingsConfigDict

class Settings(BaseSettings):
    model_config = SettingsConfigDict(env_file=".env", env_prefix="APP_")

    host: str = "0.0.0.0"
    port: int = 8080
    debug: bool = False
    token: str = Field(..., min_length=8)     # ... 表示必填

try:
    s = Settings()          # 自动读环境变量 APP_HOST / APP_PORT ...
except ValidationError as e:
    print("配置不合法:")
    for err in e.errors():
        print(f"  {err['loc']}: {err['msg']}")
    raise SystemExit(2)

print(s.host, s.port, s.debug)   # 类型已经是 int / bool，不用手动转换
```

价值：**配置错误在启动时就失败**，而不是跑到一半 `int("abc")` 崩掉。

### Dynaconf：多环境分层配置

```Python
from dynaconf import Dynaconf

settings = Dynaconf(
    envvar_prefix="MYAPP",
    settings_files=["settings.toml", ".secrets.toml"],
    environments=True,          # 支持 [default] / [production] 分层
)

settings.HOST                       # 取值
settings.get("MISSING", "默认值")   # 安全取值
settings.from_env("production")     # 切环境
```

定位：配置来源多（文件 + 环境变量 + 密钥管理）且要分环境时用它；简单脚本用 `os.environ` 就够。
