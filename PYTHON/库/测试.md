## 1. pytest ★★ —— Python 测试的事实标准

只测「纯函数」——解析、判断、格式化。这些最容易改错，改错了还不一定立刻暴露。

### 断言：直接用 assert

```Python
def test_find_problems():
    pods = [
        {"name": "a", "status": "Running", "restarts": 0},
        {"name": "b", "status": "Failed",  "restarts": 0},
        {"name": "c", "status": "Running", "restarts": 15},
    ]
    assert [p["name"] for p in find_problems(pods, threshold=10)] == ["b", "c"]
```

### 常用 fixture

```
tmp_path         临时目录（Path），自动清理
tmp_path_factory 多个临时目录
monkeypatch      打补丁：setattr / setenv / delenv / chdir
capsys           捕获 print：capsys.readouterr().out
caplog           捕获日志
request          访问测试上下文
pytest.raises(E) 断言抛异常
pytest.approx(x) 浮点近似比较
```

### 标记

```
@pytest.mark.parametrize("a,b,expect", [...])   参数化
@pytest.mark.skip(reason=) / skipif(条件, reason=)
@pytest.mark.xfail(reason=)                      预期失败
@pytest.mark.slow                                自定义标记（配合 -m）
```

### 命令行

```
pytest                    跑全部
pytest -q                 简洁输出
pytest -v                 详细
pytest -k "pod"           名字匹配
pytest -m "not slow"      按标记筛
pytest -x                 第一个失败就停
pytest --lf               只跑上次失败的
pytest -s                 不捕获输出（能 print）
pytest --cov=lib          覆盖率（需 pytest-cov）
```

```Python
import pytest

# ==== 参数化：一个函数覆盖多个用例 ====
@pytest.mark.parametrize("status,expect", [
    ("Running", "ok"),
    ("Failed", "bad"),
    ("CrashLoopBackOff", "bad"),
    ("Pending", "unknown"),
])
def test_classify(status, expect):
    assert classify(status) == expect

# ==== 断言抛异常 ====
def test_set_replicas_negative():
    with pytest.raises(ValueError, match="不能为负"):
        set_replicas(-1)

# ==== 用 monkeypatch 隔离外部依赖（不真的发请求）====
def test_fetch_pods_handles_error(monkeypatch):
    def boom(*args, **kwargs):
        raise ConnectionError("refused")

    monkeypatch.setattr("lib.client.requests.get", boom)
    assert fetch_pods() == []          # 确认降级逻辑生效

# ==== 用 monkeypatch 改环境变量 ====
def test_token_from_env(monkeypatch):
    monkeypatch.setenv("API_TOKEN", "abc")
    assert load_token() == "abc"

# ==== 临时文件 ====
def test_read_hosts(tmp_path):
    f = tmp_path / "hosts.txt"
    f.write_text("10.0.0.1\n# 注释\n\n10.0.0.2\n", encoding="utf-8")
    assert read_hosts(f) == ["10.0.0.1", "10.0.0.2"]
```

### conftest.py：共享 fixture

```Python
# tests/conftest.py
import pytest

@pytest.fixture
def sample_pods():
    """多个测试文件共用。"""
    return [
        {"name": "web-1", "status": "Running", "restarts": 0},
        {"name": "web-2", "status": "Failed",  "restarts": 12},
    ]

@pytest.fixture
def client(monkeypatch):
    """构造一个打桩过的客户端。"""
    monkeypatch.setenv("API_TOKEN", "test-token")
    return make_client()
```

```Python
# tests/test_check.py
def test_with_fixture(sample_pods):
    assert len(sample_pods) == 2
```

### 测试 CLI

```Python
from typer.testing import CliRunner

def test_cli_dry_run():
    runner = CliRunner()
    result = runner.invoke(app, ["prod", "--dry-run"])
    assert result.exit_code == 0
    assert "DRY RUN" in result.stdout
```

⚠️ 坑：

- 测试文件必须叫 `test_*.py` 或 `*_test.py`，测试函数必须 `test_` 开头
- 测试依赖**外部环境**（网络、K8s）会很不稳定，纯函数优先
- `monkeypatch.setattr` 的路径是**字符串**，指向「被调用处」而不是「定义处」
- 断言失败时只看到 `assert`，用 `assert x == y, f"实际是 {x}"` 能省很多排查时间

## 2. unittest ★ —— 标准库单测；实际项目更常用 pytest

标准库自带，知道怎么读、怎么写最基本的就行。

```
import unittest

class TestX(unittest.TestCase):
    def setUp(self): ...          每个测试前
    def tearDown(self): ...       每个测试后
    @classmethod
    def setUpClass(cls): ...      整个类前（一次性）
    def test_xxx(self): ...       方法名必须以 test_ 开头

断言:
    assertEqual(a, b) / assertNotEqual
    assertTrue(x) / assertFalse(x)
    assertIn(a, b) / assertIsNone(x) / assertIsNotNone(x)
    assertRaises(ExceptionType)        上下文管理器
    assertAlmostEqual(a, b, places=2)  浮点
```

```Python
import unittest

def classify(status: str) -> str:
    if status == "Running":
        return "ok"
    if status in ("Failed", "CrashLoopBackOff"):
        return "bad"
    return "unknown"

class TestClassify(unittest.TestCase):
    def test_running(self):
        self.assertEqual(classify("Running"), "ok")

    def test_failed(self):
        self.assertEqual(classify("Failed"), "bad")

    def test_unknown(self):
        self.assertEqual(classify("Weird"), "unknown")

    def test_raises(self):
        with self.assertRaises(ValueError):
            int("abc")

if __name__ == "__main__":
    unittest.main()
```

```Shell
python3 -m unittest test_x.py -v
```

## 3. Testinfra ★ —— 用 pytest 写法验证服务器实际状态

用 pytest 的写法验证**服务器实际状态**——装没装包、服务在不在跑、端口通不通、文件内容对不对。

定位：配置管理（Ansible）跑完之后，验证「真的达到了预期状态」，而不是相信 Ansible 的返回码。

### host fixture 提供的能力

```
host.package("nginx").is_installed
host.package("nginx").version

host.service("nginx").is_running
host.service("nginx").is_enabled

host.port(80).is_listening

host.file("/etc/nginx/nginx.conf").exists
host.file("/etc/nginx/nginx.conf").mode        # 0o644
host.file("/etc/nginx/nginx.conf").user
host.file("/etc/nginx/nginx.conf").contains("worker_processes")

host.socket("tcp://127.0.0.1:22").is_listening
host.process.filter(user="root")
host.check_output("uname -r")
host.run("df -h")                              # 返回 .rc / .stdout

host.system_info.distribution / release / arch
host.user("app").exists / .uid
```

### 运行方式

```Shell
# 1. local：验证本机
pytest --hosts='local://' test_infra.py

# 2. ssh：验证远程（需要 ssh 免密）
pytest --hosts='ssh://root@10.0.0.1' test_infra.py

# 3. ansible inventory
pytest --hosts='ansible://webservers' --ansible-inventory=hosts.ini test_infra.py
```

```Python
# test_infra.py
import pytest

def test_nginx_installed(host):
    pkg = host.package("nginx")
    assert pkg.is_installed
    assert pkg.version.startswith("1.2")

def test_nginx_running(host):
    svc = host.service("nginx")
    assert svc.is_running
    assert svc.is_enabled

def test_port_listening(host):
    assert host.port(80).is_listening

def test_config_content(host):
    conf = host.file("/etc/nginx/nginx.conf")
    assert conf.exists
    assert conf.user == "root"
    assert conf.mode == 0o644
    assert conf.contains("worker_processes auto")

def test_disk_not_full(host):
    out = host.check_output("df --output=pcent / | tail -1").strip().rstrip("%")
    assert int(out) < 90

def test_disk_not_full_via_run(host):
    r = host.run("df -h /")
    assert r.rc == 0
    assert "100%" not in r.stdout
```

⚠️ 坑：

- Testinfra 靠 SSH 连目标机，**必须配好免密**，否则会卡在密码提示
- 默认按 ssh 串行执行，机器多会很慢（可用 `-n auto` 并行）
- 它验证的是「当前状态」，不负责修复——发现问题要回到 Ansible/脚本来改
