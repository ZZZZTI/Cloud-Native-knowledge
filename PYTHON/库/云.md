## 1. boto3 ★★ —— AWS 资源管控（EC2/S3/Lambda）

AWS 官方 SDK。**核心是三分法：client（底层 API）、resource（面向对象）、paginators/waiter（分页与等待）**。

### 基本结构

```
boto3.client("ec2", region_name="ap-east-1")    底层 API，返回 dict
boto3.resource("s3", region_name="...")         面向对象封装
boto3.Session(profile_name=, region_name=)      多账号/多区域
session.client(...) / session.resource(...)

boto3.session.Config(
    region_name=,
    retries={"max_attempts": 5, "mode": "standard"},
    connect_timeout=5, read_timeout=30,
    max_pool_connections=50,
)
```

### 分页（最容易漏）

```
client.get_paginator("describe_instances")
paginator.paginate(**params)
for page in paginator.paginate(): ...    每页单独处理
paginator.paginate().build_full_result() 一次拿全（小心内存）
```

### 等待器

```
client.get_waiter("instance_running")
waiter.wait(InstanceIds=[...], WaiterConfig={"Delay": 5, "MaxAttempts": 60})
```

### 异常

```
from botocore.exceptions import ClientError
except ClientError as e:
    e.response["Error"]["Code"]        # 'NoSuchBucket' / 'AccessDenied'
```

```Python
import boto3
from botocore.exceptions import ClientError

session = boto3.Session(region_name="ap-east-1")
ec2 = session.client("ec2")

# ==== 1. 列出所有运行中的实例：必须用分页 ====
paginator = ec2.get_paginator("describe_instances")
instances = []
for page in paginator.paginate(
    Filters=[{"Name": "instance-state-name", "Values": ["running"]}]
):
    for res in page["Reservations"]:
        for inst in res["Instances"]:
            instances.append({
                "id": inst["InstanceId"],
                "type": inst["InstanceType"],
                "ip": inst.get("PrivateIpAddress"),
                "tags": {t["Key"]: t["Value"] for t in inst.get("Tags", [])},
            })

print(f"运行中 {len(instances)} 台")

# ==== 2. 按 Tag 找实例 ====
ec2_by_tag = ec2.describe_instances(
    Filters=[{"Name": "tag:Role", "Values": ["web"]}]
)

# ==== 3. 启动 / 停止 ====
try:
    ec2.start_instances(InstanceIds=["i-0123456789abcdef0"])
    # 等它真的 running，而不是 sleep(30)
    ec2.get_waiter("instance_running").wait(
        InstanceIds=["i-0123456789abcdef0"],
        WaiterConfig={"Delay": 5, "MaxAttempts": 60},
    )
except ClientError as e:
    code = e.response["Error"]["Code"]
    if code == "IncorrectInstanceState":
        print("实例状态不允许启动")
    else:
        raise
```

```Python
# ==== S3：resource 写法更顺 ====
s3 = boto3.resource("s3")
bucket = s3.Bucket("my-backup")

# 上传
bucket.upload_file("/tmp/backup.tar.gz", "2026/10/backup.tar.gz")

# 列出并挑出旧文件
from datetime import datetime, timedelta, timezone
cutoff = datetime.now(timezone.utc) - timedelta(days=30)
for obj in bucket.objects.filter(Prefix="2026/"):
    if obj.last_modified < cutoff:
        obj.delete()

# 下载
bucket.download_file("2026/10/backup.tar.gz", "/tmp/restore.tar.gz")
```

⚠️ 坑：

- **不用分页会漏数据**：绝大多数 `describe_*` / `list_*` 单次最多返回 100/1000 条
- **`region_name` 漏传**会用默认区域，可能查到另一个区的资源（甚至报「不存在」）
- 凭据顺序：环境变量 → `~/.aws/credentials` → IAM Role；别把 AK/SK 写进代码
- 限流错误码是 `Throttling` / `RequestLimitExceeded`，靠 `Config(retries=...)` 而不是自己 sleep
- `list_objects_v2` 才是新版，`list_objects` 已过时

## 2. docker ★★ —— 容器、镜像、Docker Engine API

Docker SDK for Python，直接调 Docker Engine API。

### 连接

```
import docker
docker.from_env()                        读 DOCKER_HOST / ~/.docker/config.json
docker.DockerClient(base_url="unix:///var/run/docker.sock")
docker.DockerClient(base_url="tcp://10.0.0.1:2375")   远程（⚠️ 无 TLS 等于裸奔）

client.ping()                            连通性检查
client.version()
client.info()
```

### 容器

```
client.containers.list()                 运行中的
client.containers.list(all=True)         含已停止
client.containers.list(filters={"label": "app=web"})
client.containers.get("name_or_id")
client.containers.run(
    image, command=None, name=None, detach=True,
    environment={"K": "V"}, ports={"80/tcp": 8080},
    volumes={"/host": {"bind": "/container", "mode": "rw"}},
    network="bridge", restart_policy={"Name": "always"},
    labels={"app": "web"}, auto_remove=True,
)

c.id / c.name / c.status / c.image.tags / c.labels
c.logs(tail=100, timestamps=True)        返回 bytes
c.logs(stream=True, follow=True)         生成器，逐行
c.stats(stream=False)                    一次快照（cpu/memory 需自己算）
c.exec_run("sh -c 'df -h'")              → (exit_code, output)
c.stop(timeout=10) / c.kill() / c.restart()
c.remove(force=True)
c.reload()                               重新拉取状态（状态是缓存的）
```

### 镜像

```
client.images.list()
client.images.pull("nginx:1.27")
client.images.get("nginx:1.27")
client.images.build(path=".", tag="myapp:1.0", rm=True)
client.images.remove("myapp:1.0", force=True)
```

```Python
import docker

client = docker.from_env()
if not client.ping():
    raise RuntimeError("连不上 Docker")

# ==== 1. 按标签找容器并读日志 ====
for c in client.containers.list(filters={"label": "app=web"}):
    # reload 才能拿到最新的 status
    c.reload()
    print(f"{c.name:<20} {c.status:<10} {c.image.tags}")
    tail = c.logs(tail=20, timestamps=True).decode("utf-8", errors="replace")
    if "ERROR" in tail:
        print("  最近有错误日志")

# ==== 2. 进容器执行命令（不依赖 ssh）====
code, out = c.exec_run("sh -c 'df -h / | tail -1'")
print(code, out.decode().strip())

# ==== 3. 启一个带健康检查的容器 ====
client.containers.run(
    "nginx:1.27",
    name="web-test",
    detach=True,
    ports={"80/tcp": 8080},
    environment={"TZ": "Asia/Shanghai"},
    volumes={"/data/html": {"bind": "/usr/share/nginx/html", "mode": "ro"}},
    restart_policy={"Name": "unless-stopped"},
    labels={"app": "web", "env": "test"},
)

# ==== 4. 算 CPU 使用率（stats 给的是累计值，要两次采样）====
import time
s1 = c.stats(stream=False)
time.sleep(1)
s2 = c.stats(stream=False)

cpu_delta = s2["cpu_stats"]["cpu_usage"]["total_usage"] - s1["cpu_stats"]["cpu_usage"]["total_usage"]
sys_delta = s2["cpu_stats"]["system_cpu_usage"] - s1["cpu_stats"]["system_cpu_usage"]
ncpu = s2["cpu_stats"]["online_cpus"]
print(f"CPU {cpu_delta / sys_delta * ncpu * 100:.1f}%")

mem = s2["memory_stats"]["usage"] / s2["memory_stats"]["limit"] * 100
print(f"内存 {mem:.1f}%")
```

⚠️ 坑：

- **`c.status` 是缓存值**，循环里要 `c.reload()`
- `c.logs()` 返回 **bytes**，要自己 decode
- `tcp://ip:2375` 没有 TLS = 等于把 root 权限给网络，生产必须用 socket 或 TLS 双向认证
- `auto_remove=True` 的容器退出后立刻消失，别指望还能 `get` 到
- `exec_run` 不走 shell，写 `df -h` 会失败（没有 shell 解析），要 `sh -c '...'`

## 3. kubernetes ★★/★ —— 程序化操作 K8s 资源

官方 client。**掌握度：会用「读」和「简单写」，复杂的用 YAML + `kubectl` 更省事。**

### 加载配置

```
from kubernetes import client, config

config.load_incluster_config()      Pod 里跑（读 ServiceAccount）
config.load_kube_config()           本地（读 ~/.kube/config）
config.load_kube_config(config_file="/path/kubeconfig", context="prod")
```

### 常用 API 对象

```
client.CoreV1Api()         pods / nodes / services / namespaces / configmaps / secrets
client.AppsV1Api()         deployments / statefulsets / daemonsets / replicasets
client.BatchV1Api()        jobs / cronjobs
client.NetworkingV1Api()   ingresses / networkpolicies
client.CustomObjectsApi()  自定义资源（CRD）
client.ApiClient()         底层（配 watch、自定义请求）
```

### 常用方法（以 Pod 为例）

```
v1.list_pod_for_all_namespaces(label_selector=, field_selector=, _request_timeout=5)
v1.list_namespaced_pod(namespace, label_selector=, field_selector=)
v1.read_namespaced_pod(name, namespace)
v1.read_namespaced_pod_log(name, namespace, container=, tail_lines=, since_seconds=)
v1.delete_namespaced_pod(name, namespace, grace_period_seconds=0)
v1.connect_get_namespaced_pod_exec(name, namespace, command=[...],
    stderr=True, stdin=False, stdout=True, tty=False)
v1.patch_namespaced_pod(name, namespace, body={...})
v1.create_namespaced_pod(namespace, body=...)
```

### 异常

```
from kubernetes.client.rest import ApiException
except ApiException as e:
    e.status     # 404 / 403 / 409
    e.reason
    e.body       # 原始 JSON 字符串
```

```Python
from kubernetes import client, config
from kubernetes.client.rest import ApiException

# ==== 集群内优先，本地回退 ====
try:
    config.load_incluster_config()
except config.ConfigException:
    config.load_kube_config()

v1 = client.CoreV1Api()

# ==== 1. 找出所有非 Running 的 Pod ====
pods = v1.list_pod_for_all_namespaces(
    field_selector="status.phase!=Running",
    _request_timeout=10,              # 一定要设，否则会挂住
)
for p in pods.items:
    print(f"{p.metadata.namespace}/{p.metadata.name}  {p.status.phase}")

# ==== 2. 查重启次数高的 Pod ====
all_pods = v1.list_pod_for_all_namespaces(_request_timeout=10)
for p in all_pods.items:
    for cs in (p.status.container_statuses or []):
        if cs.restart_count > 10:
            print(f"{p.metadata.name} 重启 {cs.restart_count} 次")

# ==== 3. 读日志 ====
log = v1.read_namespaced_pod_log(
    "web-1", "prod", container="app", tail_lines=100, _request_timeout=10,
)
print(log)

# ==== 4. 进容器执行命令 ====
out = v1.connect_get_namespaced_pod_exec(
    "web-1", "prod", container="app",
    command=["sh", "-c", "df -h /"],
    stderr=True, stdout=True, stdin=False, tty=False,
)
print(out)

# ==== 5. 重启 Deployment（改注解触发滚动更新）====
apps = client.AppsV1Api()
apps.patch_namespaced_deployment(
    "web", "prod",
    {"spec": {"template": {"metadata": {"annotations": {
        "kubectl.kubernetes.io/restartedAt": "2026-10-27T10:00:00Z"
    }}}}},
    _request_timeout=10,
)
```

```Python
# ==== 6. 监听事件（watch）====
from kubernetes import watch

w = watch.Watch()
try:
    for event in w.stream(
        v1.list_namespaced_pod, "prod",
        timeout_seconds=60,            # 到点退出，避免永久挂住
    ):
        p = event["object"]
        print(event["type"], p.metadata.name, p.status.phase)
finally:
    w.stop()
```

⚠️ 坑：

- 脚本用的 ServiceAccount 权限只给必需（`pods/get`、`pods/log`），别绑 `cluster-admin`
- 每个调用都加 `_request_timeout`，否则 API Server 卡住脚本就卡住
- `load_incluster_config` 需要 Pod 里有挂载的 SA token 和 `KUBERNETES_SERVICE_HOST` 环境变量
- 复杂资源建议「生成 YAML 交给 kubectl」而不是硬写 client 调用

## 4. aliyun-python-sdk-* ★ —— 各云厂商 SDK，按环境选用

各厂商 API 风格相近但不通用，按环境选。

```Python
# ==== 阿里云 ====
from aliyunsdkcore.client import AcsClient
from aliyunsdkecs.request.v20140526 import DescribeInstancesRequest

client = AcsClient(ak, sk, "cn-hangzhou")
req = DescribeInstancesRequest()
req.set_PageSize(100)
resp = client.do_action_with_exception(req)   # 返回 bytes（JSON）
```

```Python
# ==== 腾讯云 ====
from tencentcloud.common import credential
from tencentcloud.cvm.v20170312 import cvm_client, models

cred = credential.Credential(os.environ["SECRET_ID"], os.environ["SECRET_KEY"])
client = cvm_client.CvmClient(cred, "ap-guangzhou")
req = models.DescribeInstancesRequest()
req.Limit = 100
resp = client.DescribeInstances(req)
```

⚠️ 云 SDK 的三个共同坑：

1. **分页**：`NextToken` / `PageNumber`，不处理必漏数据
2. **限流**：`Throttling`，用 SDK 自带重试或自己退避
3. **区域**：漏传 region 会默认到别的区域，查到不该查的资源

```
□ boto3 知道要用 paginator，不能假设一次返回全量
□ boto3 显式传 region_name

□ k8s client 每个调用都设 _request_timeout
□ k8s SA 权限最小化
```
