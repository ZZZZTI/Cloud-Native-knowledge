### 正则 re

```python
import re

# 编译一次复用（在循环里尤其重要）
ip_re = re.compile(r"\b(?:\d{1,3}\.){3}\d{1,3}\b")
ip_re.findall(log_text)

# 常用函数
re.match(r"^ERROR", line)        # 从开头匹配，返回 Match 或 None
re.search(r"timeout=\d+", line)  # 全文找第一个
re.findall(r"\d+", "a1b22")      # ['1', '22']
re.sub(r"\s+", " ", line)        # 替换（压缩空白）
re.split(r"[,\s]+", "a, b  c")   # 切分

# 命名分组，解析日志最实用
line = '10.0.0.1 - - [25/Oct/2026:10:00:01 +0800] "GET /api/x HTTP/1.1" 502 1234'
m = re.search(r'(?P<ip>\S+) .* "(?P<method>\w+) (?P<path>\S+).*" (?P<status>\d{3})', line)
if m:
    m.group("status")      # '502'
    m.groupdict()          # {'ip': '10.0.0.1', 'method': 'GET', ...}
```

**注意**：正则不是解析器。要解析复杂结构化文本，优先找现成格式（JSON/YAML）；正则只用于行级、字段级的提取。

### JSON

```python
import json

data = {"pod": "web-1", "ready": True, "restarts": 0}

json.dumps(data)                                  # 字符串
json.dumps(data, ensure_ascii=False, indent=2)    # 中文不转义 + 美化
json.loads(text)                                  # 字符串 → 对象

with open("resp.json", encoding="utf-8") as f:
    data = json.load(f)                            # 从文件读

# 深层取值容易 KeyError，用链式 get
status = data.get("status", {}).get("phase", "Unknown")
```

`ensure_ascii=False` 是关键——默认会把中文变成 `\uXXXX`，日志里完全没法看。

### YAML

```python
import yaml

with open("deploy.yaml", encoding="utf-8") as f:
    docs = list(yaml.safe_load_all(f))     # 多文档（--- 分隔）用 load_all

yaml.safe_dump(obj, allow_unicode=True, sort_keys=False)
```

**安全**：只用 `safe_load` / `safe_dump`。`yaml.load`（不带 Loader）能构造任意 Python 对象，解析不可信输入时可被利用。

### 编码

```python
text.encode("utf-8")
```

### 实战：解析 nginx access log

```python
import re, json, collections
from pathlib import Path

LINE = re.compile(
    r'(?P<ip>\S+) \S+ \S+ \[(?P<time>[^\]]+)\] '
    r'"(?P<method>\S+) (?P<path>\S+) [^"]*" (?P<status>\d{3}) (?P<bytes>\d+)'
)

status_counter = collections.Counter()
slow_paths = collections.Counter()

for line in Path("/var/log/nginx/access.log").open(encoding="utf-8", errors="replace"):
    m = LINE.match(line)
    if not m:
        continue
    d = m.groupdict()
    status_counter[d["status"]] += 1
    if d["status"].startswith("5"):
        slow_paths[d["path"]] += 1

print("状态码分布:", status_counter.most_common())
print("5xx 最多的路径:", slow_paths.most_common(5))

# 输出结构化结果，便于接入日志平台
print(json.dumps({"5xx": status_counter["502"] + status_counter["503"]}))
```

### 实战：YAML 批量改镜像版本

```python
import yaml, sys
from pathlib import Path

NEW_TAG = sys.argv[1]

for f in Path("manifests").rglob("*.yaml"):
    docs = list(yaml.safe_load_all(f.read_text(encoding="utf-8")))
    changed = False
    for d in docs:
        if not isinstance(d, dict) or d.get("kind") != "Deployment":
            continue
        for c in d["spec"]["template"]["spec"]["containers"]:
            name, _, tag = c["image"].rpartition(":")
            c["image"] = f"{name}:{NEW_TAG}"
            changed = True
    if changed:
        f.write_text(
            yaml.safe_dump_all(docs, allow_unicode=True, sort_keys=False),
            encoding="utf-8",
        )
        print("已更新", f)
```

### 数据校验

配置和 API 响应都可能缺字段。轻量做法是显式校验：

```python
def parse_node(raw: dict) -> dict:
    for key in ("name", "status", "capacity"):
        if key not in raw:
            raise ValueError(f"缺少字段 {key}: {raw}")
    return raw
```

字段多、结构复杂时用**pydantic**（声明式校验 + 类型转换），这是目前 Python 生态的事实标准。

### 核心概念

1. **优先结构化格式**（JSON/YAML），正则只做字段级提取，不要用它解析整段结构。
2. **循环里复用 `re.compile` 的结果**，不要每次 `re.search(pattern, ...)`。
3. **`json.dumps(..., ensure_ascii=False)`**，否则中文全是转义。
4. **YAML 只用 `safe_load`**，`yaml.load` 有任意对象构造风险。
5. **读外部数据加 `errors="replace"`**，别让一条脏日志搞挂整个脚本。
6. **`DictReader`/`DictWriter` 按列名读写 CSV**，比按下标稳。
7. **边界校验前置**：缺字段就明确报错，不要等到后面 `KeyError`。
